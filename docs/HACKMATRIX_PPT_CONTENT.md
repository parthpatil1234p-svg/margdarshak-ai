## 📋 SLIDE 2: Abstract
Every year, over 2.5 crore Indian students completing Class 10 face high-stakes, irreversible academic decisions (Stream selection: Science PCM/PCB, Commerce, Arts, Vocational/Diploma). Students and parents face three crippling hurdles:
1. **Binary Bias:** Pushing every student toward JEE/NEET with zero visibility into alternative high-growth careers.
2. **Financial Blind Spots:** Incurring ₹15–20 Lakhs in private college debt without knowing starting salary ROI or monthly loan EMIs.
3. **No Contingency Planning:** Complete lack of answers to *"What if I do not clear NEET/JEE?"* or *"What if family budget is cut?"*

**MargDarshak AI (मार्गदर्शक AI)** solves this by providing:
- **Intake Profiling:** Class 10 GPA, subject affinities, family budget, location preference, and risk tolerance.
- **Sequential Multi-Pathway Maps:** Visualizing step-by-step progressions from Class 10 ➔ 11/12th ➔ UG Degree ➔ Specialization ➔ Career Entry across 3 viable routes (Primary Aspirant, Applied Industry, Cost-Optimized).
- **Interactive "What-If" Scenario Simulator:** Instant real-time pivots (e.g., NEET failure pivot to Biotech/Data Science saving ₹80 Lakhs and 2 years).
- **Financial Feasibility & Borrowing Index:** Transparent loan EMI calculation, payback years based on entry salaries, and scholarship matching.
- **Explainable Decision Matrix:** Side-by-side comparative table with transparent assumptions and AI confidence metrics.

## ⚙️ SLIDE 4: Technical Approach
* **System Architecture:**
  - **Frontend Client:** Single-Page Web Application built with HTML5, CSS3, ES6+, Bootstrap 5.3, Chart.js for financial payback analytics, and responsive SVG/Canvas pathway nodes.
  - **Backend REST API:** Node.js (v18+) with Express.js, Helmet security, CORS, and modular services (`pathwaySimulationService`, `loanCalculatorService`, `whatIfEngineService`, `aiReasoningService`).
  - **Database & Data Store:** MongoDB / Mongoose with realistic seeded datasets covering Indian streams, top institutions (IITs, COEP, PCCOE, BITS, AIIMS, German Public Universities), careers, and scholarships.
  - **Dual-Engine AI Intelligence:** Google Gemini API (`gemini-1.5-flash` / `gemini-2.5-flash`) with structured JSON schema outputs + high-speed Deterministic Heuristic Fallback Engine to ensure 100% live demo reliability without API key dependency.

* **Sequential Progression Engine:**
  `Class 10 Intake` ➔ `Stream Fit Analysis` ➔ `3-Tier Pathway Generation` ➔ `Financial Feasibility Scoring` ➔ `Dynamic What-If Pivots`.
